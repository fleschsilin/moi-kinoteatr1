# Проверенная библиотека фильмов

Бот больше не ищет случайные видео по всему Internet Archive. Единственный источник публикаций — `library.json`.

## Добавление фильма

Добавлять фильм в массив `films` можно только после ручной проверки:

1. Убедиться, что запись действительно является полнометражным фильмом, а не клипом, записью стрима или пользовательским видео.
2. Проверить оригинальный источник и конкретный файл.
3. Проверить лицензию и доказательство права на распространение именно этой копии. Метаданные Archive.org и указанная загрузчиком лицензия сами по себе не являются достаточным доказательством: Archive.org прямо предупреждает, что не гарантирует точность заявлений загрузчиков.
4. Проверить, что права допускают распространение в Казахстане (KZ). Статус public domain в США автоматически не означает public domain в Казахстане.
5. Проверить содержание и исключить шокирующие материалы, незаконный контент и неподходящие для канала ролики.
6. Заполнить все поля ниже и поставить `approved: true` только после проверки.

## Формат записи

```json
{
  "identifier": "точный-id-на-archive-org",
  "title": "Название фильма",
  "year": 2020,
  "director": "Режиссёр",
  "language": "ru",
  "synopsis": "Краткое проверенное описание",
  "genre": "Драма",
  "license_url": "https://creativecommons.org/licenses/by/4.0/",
  "rights_basis": "written_permission_or_verified_cc_license",
  "rights_evidence_url": "https://example.org/rights-proof",
  "rights_status": "verified",
  "rights_territories": ["KZ"],
  "content_review": "passed",
  "reviewed_by": "редактор",
  "reviewed_at": "2026-11-20",
  "approved": true
}
```

Разрешены только HTTPS-ссылки на Creative Commons CC0, CC BY и CC BY-SA из списка в коде. Лицензия в каталоге должна совпадать с лицензией, возвращаемой метаданными источника. Запись с неподтверждёнными правами или без подтверждения для KZ не пройдёт проверку.

## Текущий статус

Каталог намеренно создан пустым. Это безопаснее, чем выдавать случайные ролики за проверенные фильмы. Пока нет подтверждённых записей, публикация невозможна. `DRY_RUN=true` остаётся обязательным режимом GitHub Actions.


## Очередь официальных открытых фильмов

Файл `film_research_queue.json` содержит кандидатов с лицензиями, опубликованными непосредственно на официальных страницах создателей:
- Big Buck Bunny — Blender Foundation, CC BY 3.0
- Sintel — Blender Foundation, CC BY 3.0
- Tears of Steel — Blender Institute, CC BY 3.0

Это **не одобренные записи библиотеки**. Наличие открытой лицензии на официальной странице подтверждает заявленные условия распространения, но перед включением в `library.json` требуется проверить конкретный скачиваемый файл, сохранить обязательные титры, подготовить совместимую с Telegram версию и полностью просмотреть содержание. Для Tears of Steel отдельно проверить русские субтитры. Статусы кандидатов отражены в JSON.

Источники лицензий:
- Big Buck Bunny: https://peach.blender.org/about/
- Sintel: https://durian.blender.org/sharing/
- Tears of Steel: https://mango.blender.org/about/

Не переносить кандидата в `library.json`, пока все блокирующие проверки не завершены. Публикация остаётся выключенной.


## Подготовка исходников для Telegram

Подготовка вынесена в `scripts/prepare_movies.py` и запускается вручную отдельным GitHub Actions workflow `Prepare open movie candidates`. Он не использует токен бота и не публикует сообщения.

Что делает pipeline:
1. Загружает только HTTPS-ссылки из очереди официальных кандидатов.
2. Сохраняет SHA-256 исходного архива/файла.
3. Распаковывает ZIP с защитой от path traversal.
4. Проверяет видеопоток и длительность через ffprobe.
5. Перекодирует в H.264/AAC MP4 с faststart и двухпроходным кодированием, целевой размер — не более 48,000,000 байт.
6. Сверяет длительность результата с исходником, чтобы обнаружить обрезку начала/конца.
7. Скачивает русские SRT отдельно, проверяет базовую структуру и сохраняет sidecar-файл.
8. Создаёт `prepared_manifest.json` с размерами, SHA-256, параметрами и статусами проверки.
9. Загружает подготовленные файлы как временный GitHub Actions artifact на 7 дней.

Это техническая подготовка, а не одобрение: автоматическая проверка не может доказать, что в кадре сохранились финальные титры, что субтитры синхронны или что весь фильм подходит каналу. Полный просмотр и проверка прав/территории остаются обязательными. Результаты не копируются в `library.json` автоматически.
